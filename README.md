# Kohaku

A kitsune shrine maiden in miko robes. Pet the top of her head. A slow hand makes her happier than a fast one.

## Play

Download the program for your computer from [Releases](https://github.com/delusionalcookie/Kohaku/releases) and open it. Your browser opens the shrine. Leave the Kohaku window open while you play, and close it when you are done.

On Windows, if SmartScreen appears, choose More info, then Run anyway. The file is not code-signed.

## Work on it

```
npm install
npm run dev
```
